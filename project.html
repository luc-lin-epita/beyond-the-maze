Gameplay

Beyond The Maze propose une expérience immersive basée sur l’exploration. Le labyrinthe évolue avec le temps, et les ennemis sont agressifs envers le joueur. Le joueur doit alors faire des choix stratégiques pour survivre et récupérer sa mémoire. Il va devoir réfléchir face aux petites énigmes qui vont l'aider à progresser dans le labyrinthe.

Caractéristiques principales

  • Labyrinthe dynamique et imprévisible
  • Ambiance mystérieuse
  • Survie et exploration
  • Recherche de la mémoire

Technologies et ressources utilisées

  • Python – langage principal du projet
  • Panda3D – moteur 3D utilisé pour développer le jeu
  • Documentation Panda3D – utilisée pendant le développement
  • Documentation Python – référence pour le langage de programmation utilisé
  • GitHub – hébergement du code et du site web
