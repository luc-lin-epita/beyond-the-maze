Gameplay

Beyond The Maze propose une expérience immersive en vue à la première personne, dans un labyrinthe généré algorithmiquement qui incarne la prison mentale de Kael. Les murs ne sont pas de simples obstacles : ils portent les souvenirs dissociés du personnage, fragmentés et superposés. Plus vous vous enfoncez dans le labyrinthe, plus les textes gravés dans la pierre deviennent lisibles — révélant l’enquête de Kael, sa capture, et les preuves qu’il voulait rendre publiques.

Une menace rôde dans les couloirs : le Réviseur, manifestation de la procédure d’Effacement elle-même. Il ne traque pas par haine — il agit par réflexe, comme un anticorps, pour effacer tout sujet qui se souvient trop. L’affronter ou l’éviter est votre choix — mais il est possible de le vaincre, grâce à une faille que l’Ordre lui-même ignorait.

Caractéristiques principales

  • Labyrinthe généré algorithmiquement, hostile et oppressant
  • Narration environnementale : les souvenirs de Kael sont gravés dans les murs
  • Survie face au Réviseur, gardien automatique de l’Effacement
  • Progression narrative inversée : du quotidien aux révélations les plus profondes
  • Dénouement ouvert sur le monde réel — et sur les responsables de l’Ordre

Technologies et ressources utilisées

  • Python – langage principal du projet
  • Panda3D – moteur 3D utilisé pour développer le jeu
  • Documentation Panda3D – utilisée pendant le développement
  • Documentation Python – référence pour le langage de programmation utilisé
  • GitHub – hébergement du code et du site web
